# Nicholibb

**Builder working on local LLM tooling, multi-agent systems, and small tools that stay on your machine.**

I like problems where the answer has to run on hardware you own: a workstation, a laptop, a browser tab. Most of my work is Python, TypeScript and FastAPI, with a strong bias toward *local-first*: no account, no upload, no server bill. I also run a small crew of agents (coordinator, researcher, reviewer, engineer) as part of the build loop.

## Featured

| Project | What it is | Stack |

| **[agent-office](https://github.com/nicholibb-prog/agent-office)** | A cartoon 3D office where a team hires coding agents at desks, shares live terminals, talks over voice, and tracks GitHub work | TypeScript, 3D, voice |
